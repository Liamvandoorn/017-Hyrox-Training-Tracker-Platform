🎯 KEY FEATURES
═══════════════════════════════════════════════════════════════════════════════

✅ SECURITY
   • Passcode-protected access
   • Environment variable configuration
   • Session-based authentication
   • localStorage for client-side persistence

✅ DATABASE
   • PostgreSQL via Neon (cloud)
   • Connection pooling with pg driver
   • Indexed queries for performance
   • Table auto-creation on init

✅ PWA (Progressive Web App)
   • Web app manifest for installation
   • Mobile-responsive design
   • Works on iOS and Android
   • Installable as standalone app

✅ USER INTERFACE
   • Dark grey (#2a2a2a) theme
   • Off-white (#f5f5f5) text
   • Tailwind CSS styling
   • Touch-friendly components

✅ TRAINING DATA
   • Exercise type (12 Hyrox exercises)
   • Training date
   • Duration (minutes)
   • Distance (km) - optional
   • Training notes - optional
   • Automatic timestamps

🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. INSTALL DEPENDENCIES
   $ npm install

2. SET UP DATABASE
   Visit: https://console.neon.tech
   • Create PostgreSQL project
   • Copy connection string

3. CONFIGURE ENVIRONMENT
   Create .env.local with:
   DATABASE_URL=postgresql://...
   NEXT_PUBLIC_PASSCODE=1234

4. INITIALIZE DATABASE
   $ npm run init-db

5. START DEVELOPMENT
   $ npm run dev
   Open: http://localhost:3000
   Passcode: 1234
